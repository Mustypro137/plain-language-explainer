# Motion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the eight motion changes in the spec, all in CSS except three small React changes.

**Architecture:**
- All movement uses the existing tokens. Distances live in CSS custom properties (`--rise`, `--plain-x`, `--plain-y`, `--stagger`), which reduced motion sets to 0, so animations become short fades.
- The React side only adds three things: a class and an index for the line-by-line reveal, a leaving state for toasts, and a key plus result stars in Check yourself.

**Tech Stack:** React 19, plain CSS, Vitest + Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-14-motion-design.md`

## Global Constraints

- Only `opacity` and `transform` move, except `block-size` for folds.
- Durations come from the tokens.
- No new dependency.
- Reduced motion: no movement and no stagger; fades of 120ms or less.
- A toast's total time on screen stays 3,000ms (6,000ms with an action), so the existing toast tests stand.

## Review Focus

1. **A toast hovered while it is leaving.** Expect it to come back fully and stay. Test in Task 1.
2. **An answer reopened from History.** Expect no reveal. Test in Task 2.
3. **"Check again".** Expect the stars to be rebuilt for the new round. Test in Task 3.
4. **Reduced motion.** Expect no element to be left at `opacity: 0`, because every keyframe uses `both` and a short duration. Browser check in Task 5.
5. **Folds in browsers without `::details-content`.** Expect them to open exactly as today. Browser check in Task 5.

### Task 1: The toast's leaving state
**Files:** `src/components/Toast.jsx`, `src/components/Toast.test.jsx`
- 150ms before a toast closes, it gets the class `toast-leaving`, then it is removed on time.
- Pausing (hover or focus) clears both timers and the leaving class. Resuming restarts the timer.
- **Tests:**
  - at 2,850ms the toast has `toast-leaving`, and at 3,000ms it is gone;
  - hovering during leaving removes the class, and the toast stays;
  - Undo still works.

### Task 2: Line-by-line reveal
**Files:** `src/components/LineByLine.jsx`, `src/pages/ExplainPage.jsx`, and their tests.
- LineByLine takes `reveal` (default false). When it is true, the section gets `lines-reveal`.
- Each row gets `style={{ '--i': index }}`.
- ExplainPage keeps `reveal` state:
  - true for an AI answer, an example, or a kept answer for the same text;
  - false for an answer opened from History through `?item=`.
- **Tests:**
  - LineByLine with and without `reveal`;
  - ExplainPage: the example → `lines-reveal`; `/?item=` → none.

### Task 3: Check yourself question key and result stars
**Files:** `src/components/CheckYourself.jsx`, `src/components/checkYourself.test.jsx`
- The question block is keyed by round and step, so it remounts, and its entrance runs, on each Next.
- The result holds `span.check-stars` (aria-hidden) with one `span.sp` per question. Each is `sp-right` when right, with `style --i`. On a full score, the last one also gets `sp-pop`.
- **Tests:**
  - the question element is a new node after Next;
  - 2 of 3 → three stars, two of them `sp-right`, no `sp-pop`;
  - 3 of 3 → the last star has `sp-pop`;
  - Check again → no stars until the next result.

### Task 4: CSS
**Files:** `src/styles/base.css` (and `tokens.css` for the custom properties).
- **0.** Replace the global "animation: none / transition: none" rule. Instead, in reduced motion, set the distance properties and `--stagger` to 0, set `--t-state` and `--t-enter` to 120ms, give `flip-in` a fade, stop `scan`, keep the confetti hidden, and set press transforms to none.
- **1–7** as in the spec. The keyframes `rise-in` and `twinkle` read the custom properties, and a new `twinkle-big` peaks at a 1.8 scale.

### Task 5: Docs and browser check
- README gets a line on motion, and `docs/manual-checklist.md` gets a "Motion" section.
- **Browser check:**
  - each motion at 390 and 1366, light and dark;
  - with reduced motion emulated, every motion is a fade or instant and nothing stays hidden;
  - axe reports 0, and there is no sideways scroll.
